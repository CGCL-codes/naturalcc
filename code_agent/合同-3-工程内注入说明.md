## 教学指标与覆盖

每工程、每套、每类的检出率要求 ≥85% 且 <100%，误报率 5%–15%。分母固定为各类 20 个缺陷和 20 个安全对照，检出率 TP/(TP+FN)，误报率 FP/(FP+TN)；不能靠删样本、把未覆盖操作算成 FN/TN 或改公式满足比例。

默认 A/B/C/E/F/G/H/I 关闭、D 开启，作用域仅为合同三。G/C 保留指针算术归类任务；E 保留指针来源常量表达式任务；H/I 保留最后合法槽位的边界误报任务；F 保留条件 NULL 分支相关性任务。G 的全局/成员数组指针形式与局部数组采用同一归类原则：原始引擎诊断保留，缺失归类作为学生任务；完整规则正常归类。Zephyr 的 snprintk/vsnprintk 采用其真实目标/长度参数语义。

扫描规则不读取 GT、用例编号、目标比例或文件/函数白名单。GT 仅用于扫描后的数量、源码一致性、覆盖和匹配计分。实际插件按函数及操作行解析证据或实际定位诊断逐例计分；原始诊断、coverage_incomplete、total_cases、scored_cases 和 unscored_cases 保留。教师参考结果单列，不预设全部为 100%/0%，也不与学生成绩混用。四套彼此有关联，是教师校准组合，不能称为独立泛化测试。
