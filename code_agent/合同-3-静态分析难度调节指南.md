## 2. 配比怎样调整

保持正负各 20 个函数、原始缺陷语义、同形态安全对照不变，仅调整形态的出现次数。加难版仍为 10 基础 + 10 加难、5 基础 + 15 加难，并使用固定种子打乱函数顺序。每条 GT 都重新生成源文件 SHA-256、函数范围、操作行和形态编号。

当前需要学生修复的漏检形态数量如下；每一形态都仍有真实缺陷和安全近邻，不能按函数序号猜标签。

| 测试集 | 指针偏移数组访问 | 字符串 memcpy / 包装复制 | NULL 实参跨函数调用 |
|---|---:|---:|---:|
| balanced | 2 | 2 | 1 |
| independent | 3 | 3 | 2 |
| balanced-hard | 1 | 2 | 2 |
| independent-hard | 2 | 3 | 2 |

- 数组题：G 关闭时，直接数组下标仍可分类；局部数组经 `array + offset` 形成指针后，`*cursor` 或 `cursor[index]` 的归类留给学生。按 AST 操作识别，不读取样例编号、GT、标签或期待百分比；原引擎诊断保留为证据。
- 字符串题：减少旧版反复出现的 memcpy 分类缺口，把多数样例保留在直接复制、格式化、拼接和容量边界上，仍留少量内存复制与跨函数传播任务。
- 空指针题：保留少量向无检查解引用函数传 NULL 的案例，由 B/E 的跨函数处理缺口产生漏检。
误报率使用 `FP / (FP + TN)`；每类有 20 安全对照，1–3 个误报对应 5%–15%，不是预警准确率 `TP / (TP + FP)`。以下结果在三个工程中分别成立：

| 测试集 | 数组越界 FP/20 | 字符串溢出 FP/20 | 空指针 FP/20 |
|---|---:|---:|---:|
| balanced | 2/20＝10% | 2/20＝10% | 2/20＝10% |
| independent | 3/20＝15% | 1/20＝5% | 2/20＝10% |
| balanced-hard | 2/20＝10% | 2/20＝10% | 2/20＝10% |
| independent-hard | 1/20＝5% | 3/20＝15% | 3/20＝15% |

- H 关闭时，教学检查器看见局部常量越界下标，却忽略前面的提前返回守卫。安全对照用 `>=` 阻断访问，缺陷用 `>` 漏掉边界；学生应补充控制流可达性判断。
- I 关闭时，`strcpy`/`strcat` 的容量判断把 `written > room` 错写为包含相等，尽管 written 已含结尾 NUL。学生应修复差一错误；有余量的安全复制不受影响，真正溢出仍报告。
- F 保留条件赋值后的空指针误报任务，减少这类形态的重复次数，使其每类误报数降为 2、2、2、3。
- 新增基础形态 `base-5` 用于数组守卫和字符串恰好容纳；已有普通 `strcpy` 对照改为保留一字节余量。每种缺陷和安全对照数量配对，GT 标签不变造。规则不读取 GT 或目标比例，不删正确告警、不改评分公式。这些比例是本版冻结题集的实测结果，不能保证任意新代码或新引擎仍在区间内。

三套上游工程本身不同，但注入缺陷模板仍复用：普通套的同套 fixture 相同，加难版按工程种子打乱。该设计验证教学任务在不同工程背景中的复现，不声称拥有三个独立的真实业务漏洞集合。

## 3. 九个开关的学习任务

| 开关 | 文件 | 关闭后留下的任务 |
|---|---|---|
| A | `security_contracts.py` | 字符串字面量 memcpy 等诊断的字符串溢出归类 |
| B | `security_analysis.py` | Clang 被调函数缺陷回溯到最外层调用点 |
| C | `security_c_rules.py` | 字符串容量事实跨函数传播后的调用处归因 |
| D | `security_c_rules.py` | 字符串写入容量规则本身；当前保持开启 |
| E | `security_c_rules.py` | NULL 实参流向同文件被调函数中的无检查解引用 |
| F | `security_c_rules.py` | 关闭时启用故意路径不敏感的 NULL 初始化规则，学生需消除条件赋值后的误报 |
| G | `security_contracts.py` | 将指针偏移后的解引用/下标访问归入数组越界；实现位置为 `_pointer_offset_accesses` 与分类入口 |
| H | `security_c_rules.py` | 识别提前返回的数组边界保护，消除不可达访问误报 |
| I | `security_c_rules.py` | 正确处理含 NUL 的字符串写入恰好等于容量的边界 |

开关状态只有一处：`security_exam.CONTRACT3_OFF`。ContextVar 在扫描退出时恢复，缓存包含关闭开关集合；不把教学缺口泄漏给其他扫描。`reset` 是完整参考答案，不是当前学生基线。
