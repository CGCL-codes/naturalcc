# 测试主题：JavaScript 前端交互 - 计算器应用

这是一个用于测试 coding agent 创建/修改 JavaScript 前端项目的项目。

## 测试目标
- 测试 agent 是否能正确处理 DOM 操作和事件监听
- 测试 agent 是否能正确实现计算逻辑（加减乘除、括号、小数）
- 测试 agent 是否能正确处理错误状态（除零、非法输入）
- 测试 agent 是否能正确处理键盘输入和按钮点击

## 项目结构
```
project_02_js_calculator/
├── README.md
├── index.html         # 主页面
├── style.css          # 样式表
├── calculator.js      # 计算器逻辑
└── tests/
    └── calculator.test.js  # 测试用例
```
