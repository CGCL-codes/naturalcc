# 测试主题：Python 数据处理与可视化

这是一个用于测试 coding agent 数据处理能力的项目。

## 测试目标
- 测试 agent 是否能正确使用 pandas 进行数据处理
- 测试 agent 是否能正确生成数据可视化图表
- 测试 agent 是否能正确处理缺失数据和异常值
- 测试 agent 是否能正确进行统计分析
