# 测试主题：C++ 算法实现与数据结构

这是一个用于测试 coding agent C++ 编程能力的项目。

## 测试目标
- 测试 agent 是否能正确实现经典排序算法
- 测试 agent 是否能正确处理模板和 STL
- 测试 agent 是否能正确管理内存和指针
- 测试 agent 是否能正确处理链表、栈、队列等数据结构

## 项目结构
```
project_04_cpp_algorithm/
├── README.md
├── CMakeLists.txt        # 构建脚本
├── include/
│   ├── sorting.h         # 排序算法
│   └── linked_list.h     # 链表实现
├── src/
│   ├── main.cpp          # 主程序
│   ├── sorting.cpp       # 排序实现
│   └── linked_list.cpp   # 链表实现
└── tests/
    └── test_main.cpp     # 测试程序
```
