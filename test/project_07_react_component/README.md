# 测试主题：React 组件开发与状态管理

这是一个用于测试 coding agent React 编程能力的项目。

## 测试目标
- 测试 agent 是否能正确创建函数式组件和 Hook
- 测试 agent 是否能正确处理 props 和 state
- 测试 agent 是否能正确实现组件组合
- 测试 agent 是否能正确处理异步操作和副作用

## 项目结构
```
project_07_react_component/
├── README.md
├── package.json
├── public/
│   └── index.html
└── src/
    ├── index.js            # 入口
    ├── App.js              # 主组件
    ├── components/
    │   ├── TodoList.js     # Todo 列表组件
    │   ├── TodoItem.js     # 单个 Todo 项
    │   └── TodoForm.js     # Todo 表单组件
    └── hooks/
        └── useTodos.js     # 自定义 Hook
```
